About Me 🌟

Hi! My name is SaraKat.

This is my GitHub portfolio, created as a final project for an Intro to CS course. I went into this class with minimal computer science knowledge. I had learned of the subject previously in maybe Elementary or Middle School but I appreciated the opportunity to dive more into the world of CS. Although I had a rough start in the course, I think I prevailed pretty well. I started with basic topics such as problem solving, learning about AI, app design, and how to code in JavaScript using a Turtle. Then, as our curriculum progressively got more advanced, I learned about the ethics of CS, how to design both apps and websites, and in turn, how to build my portfolio
